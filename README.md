# Meldeformular Laternen-Ausfall.de

Zentrale Formularseite, über die Bürger defekte Straßenbeleuchtung an ihre Kommune melden.
Aufruf mit dem Formularschlüssel der Kommune: `https://mariolol2000.github.io/laternen-ausfall-formular/?k=<schlüssel>`

Die Seite enthält nur öffentliche Werte; jede Meldung prüft der Server.
Sie wird im Hauptprojekt mit `tool/formularseite_bauen.py` erzeugt und hier nur veröffentlicht. Bitte nicht direkt bearbeiten.
